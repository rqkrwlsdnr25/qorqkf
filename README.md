# 백발의 유성 — 산속의 열세 갈래 v0.3

산속 한 지역에서 시작하는 선택형 비주얼노벨 게임입니다. 서브 플롯 10개, 메인 플롯 3개, 준비된 이야기 선택지 66개, 결말 8개를 포함합니다. 66개는 모든 분기의 합계이며 한 회차에 전부 등장하지 않습니다. 전투 및 휴식 버튼은 이 수에 포함하지 않습니다.

## 실행

1. `releases/white-meteor-v0.3-full.zip`을 내려받아 압축을 풉니다.
2. `PLAY.html`을 최신 Chrome, Edge 등에서 엽니다.
3. 지효 또는 백호를 선택하고 **다음 턴**을 누릅니다.

PLAY.html에는 코드·데이터·스타일이 모두 들어 있습니다. API 키나 서버 없이 실행하도록 만들었습니다. 브라우저가 로컬 파일 저장을 제한하면 **기록 파일 내보내기**로 JSON을 보관하세요. 다른 기기·브라우저로 이동할 때도 JSON을 가져와 이어갈 수 있습니다.

모듈 소스를 실행하려면 `python -m http.server 8000 --directory dist` 후 `http://localhost:8000`을 엽니다. 정적 호스팅 배포 대상은 `dist/`입니다.

## 진행 방식

- 작은 사건은 원하는 순서대로 선택합니다. 사건 열기·접기에는 턴이 들지 않습니다.
- 서브 플롯 3개, 6개, 10개를 완료하면 각각 다음 메인 플롯이 이어집니다.
- 서브 선택은 주인공의 능력치, 동료의 신뢰, 약초, 후속 단서에 영향을 줍니다.
- 큰 사건은 정찰자 접촉 → 습격 여부 → 산속 이야기의 결말 순서로 이어집니다.
- 앞선 준비에 따라 뱀의 직접 개입, 부하들의 습격, 공격 없는 대치로 갈립니다.
- 결과가 확정되면 전체 턴이 1 증가합니다. 전투 라운드는 별개이며 전투 종료 때 사건 턴이 한 번 완료됩니다.
- 날짜는 거처에서 **밤을 보낸다**가 완료될 때만 증가합니다. 사건과 전투 도중에는 취침할 수 없습니다.
- 끝난 서브 플롯은 반복할 수 없습니다. 결말 후에는 새 역사를 시작합니다.

## 저장 호환

v0.3 자동 저장(`meteor-v03-auto`)과 수동 저장(`meteor-v03-manual`)은 이전 키와 분리됩니다. 선택 대기, 시드 난수, 전투 라운드, 단서, 결말을 저장합니다.

v0.1/0.2를 가져오면 날짜·완료 턴·주인공 능력치를 이어받고 새로운 13개 플롯은 처음부터 시작합니다. 이전 관계·기억·지도·미완료 사건을 새 분기로 억지 변환하지 않습니다. 원본 저장 전체는 `legacyArchive`에 보관되며 기존 브라우저 저장도 덮어쓰지 않습니다. 기존 관계 수치가 새 플레이에 적용되지는 않습니다.

## 개발

- `dist/data/plots.json`: 모든 사건·선택·조건·효과·결말
- `dist/data/world.json`: 한 지역과 기존 캐릭터 기본 데이터
- `dist/js/story-manager.js`: 분기, 판정, 턴·날짜, 저장 변환
- `dist/js/engine.js`: 캐릭터 초기화·기억·판정·전투 핵심
- `dist/js/game.js`: 화면과 저장 UI
- `CONTENTS.md`: 제작자용 전체 분기표 (스포일러)
- `VALIDATION.md`: 실제 검증과 한계

```sh
npm test
python scripts/build_standalone.py
python scripts/package_release.py
```

이 버전의 세부 사건·대사·분기는 게임용 창작 초안입니다. 원작의 확정 설정으로 간주하지 않습니다. 무한 AI 채팅·자유 입력·자동 NPC 세계 시뮬레이션은 이번 유한 플롯 구조에서 사용하지 않습니다. 다른 지역과 후속 장은 아직 없습니다. 기존 v0.2 ZIP은 GitHub에 보존합니다. 이전에 배포된 Sites 주소는 이번 GitHub 패치로 자동 갱신되지 않습니다.

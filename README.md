# 백발의 유성 v0.4 — 유성 아래의 첫 만남

백호가 유성에서 내려와 지효를 처음 만나는 선택으로 시작합니다. 지효는 어머니를 치료하고 싶어 하고, 백호는 지효를 따라온 기척을 느낍니다.

## 메인 플롯 3개

1. 유성에서 내려온 백호: 첫 대화와 지효의 부탁.
2. 지효를 따라온 것: 전투, 준비된 도주, 흔적을 숨기는 우회, 상처를 감수하는 탈출.
3. 어머니가 기다리는 집: 첫 대면과 치료·간호의 시작.

## 서브 플롯 5개

1. 어머니에게 가야 하는 이유: 증상 듣기/동행 약속/거리 두기.
2. 뒤따르는 발소리: 방향 파악/신호 공유/흔적 숨기기.
3. 도망친 뒤의 숨: 상처 돌보기/우회로/서두르기.
4. 문턱에 닿기 전: 주변 확인/조용한 접근/어머니 부르기.
5. 치료를 부탁하는 마음: 솔직한 약속/물과 천 준비/어머니 의사 확인.

첫 만남 → 서브 2개 → 추적자 대치 → 나머지 서브 3개 → 어머니의 집 순서입니다. 증상 청취는 조심스러운 힘 사용을, 치료 준비는 간호 선택을 엽니다. 도주와 은밀한 우회는 앞선 관찰·신호·흔적 숨기기로 해금됩니다. 준비 없이도 상처를 감수하며 탈출할 수 있습니다.

이번 이야기는 어머니를 완치하지 않습니다. 상태가 잠시 안정되거나, 함께 간호하고 지키는 세 결말로 마칩니다. 추적자의 정체는 확정하지 않았습니다. 세부 대사는 게임용 초안입니다.

압축을 풀고 PLAY.html을 여세요. 일반 행동으로 날짜가 바뀌지 않으며, 밤 보내기만 날짜를 넘깁니다. 전투 라운드와 이야기 턴은 별개입니다. v0.4 자동 저장은 meteor-v04-auto 키를 사용합니다. 이전 저장을 JSON으로 가져오면 날짜·턴·능력치를 보존하되 새 이야기를 첫 만남부터 시작하며 원본은 legacyArchive에 보관합니다.

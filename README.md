# 백발의 유성 v0.5 — Chapter / Stage 패치

기존의 서브플롯 해금 목록을 폐지하고 현재 장면에 종속된 선택지만 노출하는 Chapter → Stage 구조로 변경했습니다.

## 이야기 구조

- 0장 프롤로그 · 만남: 유성을 따라 산에 오른 지효가 백호와 처음 만나고, 아픈 어머니를 도와달라고 부탁한 뒤 함께 집으로 향합니다.
- 1장 지효를 쫓아온 습격자들: 전투 / 은신 / 도주 경로로 분기합니다. 은신 및 일부 도주 선택은 신뢰와 별도로 호감·설렘이 상승합니다.
- 2장 지효의 집: 겉보기엔 건강하고 밝은 어머니와 평범한 대화를 나눈 뒤, 지효가 자리를 비운 사이 백호가 지효가 “악마의 아이”라 불려 온 사정을 듣습니다.

## 시스템 변경

- state.story.active.plot 과 active.node 가 현재 장/장면을 결정합니다.
- UI는 현재 Stage 선택지만 표시하고, 장이 끝나면 이전 장 선택지는 다시 후보로 나오지 않습니다.
- 관계 수치: 신뢰 / 호감 / 설렘.
- v0.5 저장 키를 사용하며 v1~v4 저장은 능력치와 날짜를 보존해 마이그레이션합니다.
